# Корпус E Ink часов — параметрическая модель

Папка: `/workspace/e-ink-watch-case/`  
Связанная PCB: `/workspace/e-ink-watch-kicad/` (Ø40 мм, FPC на 12/9/3, SW1–3 нижняя-правая дуга, J_BAT на 6 ч).

## Решение по зарядке + программированию

**Заднее окно pogo под комбинированную cradle-колодку (зарядка + SWD). USB-C нет.**

Матрица **2×3 = 6 контактов**, шаг **3.0 mm**, центр ≈ (−4.0, −12.5) мм — между зонами J_BAT (6 ч) и J_SWD (нижний-левый):

| # | Net | Назначение |
|---|-----|------------|
| 1 | VCHG | зарядка (VBUS к PMIC) |
| 2 | GND | общий |
| 3 | SWDIO | отладка |
| 4 | SWDCLK | отладка |
| 5 | nRESET | сброс MCU |
| 6 | OPT | опционально: 3V3_sense / ID / NC |

Допуск соосности cradle ↔ корпус ↔ площадки PCB: **±0.2 mm**. Ключ-паз на −X окна — защита от разворота на 180°. На PCB нужны ответные **B.Cu pads** (не только разъём J_SWD сверху).

## IP67 — design intent (зафиксировано)

**Цель: IP67** (пыль + погружение **1 m / 30 min**, IEC 60529).

| | |
|--|--|
| Статус | **Design intent** — посадка уплотнений и CAD-карманы |
| Сертификация | **Не лабораторно сертифицировано** до прохождения IP-теста |
| Не заявлено | IP65 / IP68 (цель только IP67) |
| SoT | `reports/IP67_SEALING.md`, `exports/SEAL_PARAMS.txt` |
| PCB | `/workspace/e-ink-watch-kicad/reports/IP67_PCB_IMPACTS.md` |

Ключевые барьеры: silicone cord на split, glass bond + PORON, button boots, FPC plugs 3/9, **sealed pogo** (эластомер поверх pads, cradle сжимает; SW_DBG только внутри).

Маркировка / README / маркетинг до lab: писать **«IP67 design intent — not lab-certified»**, не «IP67 certified».

## Стек по оси Z (снизу вверх)

См. подробно `MECHANICAL.md`. Кратко:

`задняя стенка 1.4 → полость батареи 3.6 → PCB 0.8 → SPLIT 6.0 → стекло/безель → верх 11.0`

Разъём половины корпуса (`SPLIT_Z`) = **6.0 mm** от низа (P0: cavity 3.6 → PCB top 5.8).

**IP67** — design intent (`IP_CERTIFIED=False`). См. `reports/IP67_SEALING.md`, `reports/FIX_P0.md`.

## BOM пластика (печать)

| Деталь | Файл | Кол-во | Примечание |
|--------|------|--------|------------|
| Низ / зад | `exports/case_bottom.stl` | 1 | Pogo, батарея, бобышки, ушки |
| Верх / безель | `exports/case_top.stl` | 1 | Окно дисплея, тоннели кнопок |
| Клавиша | `exports/button_cap.stl` | 3 | Актуator; зеркалить не нужно |
| Сборка (превью) | `exports/case_assembly.stl` | — | top∪bottom, не для печати целиком |

Рекомендуемый филамент: **PETG** или **ABS/ASA** (ударопрочность, чуть лучше герметизация клеем); PLA — только прототип. Слой 0.15–0.2 mm, стенки ≥2 периметра (≥0.8 mm), заполнение бобышек 40–100%.

Дополнительно (не пластик): винты M1.4×L≈6–8; **IP67 seal BOM** — silicone cord Ø1.0, pogo elastomer sheet (+conductive pills), button boots×3, PORON под стекло, FPC silicone plugs, foam под LiPo; cradle pogo + зарядная колодка. Полный список: `reports/IP67_SEALING.md`.

## Как пересобрать

```bash
# CadQuery уже ставится так:
pip3 install --break-system-packages cadquery

cd /workspace/e-ink-watch-case
python3 src/watch_case.py
```

Параметры — в начале `src/watch_case.py` (`CASE_OD`, `OVERALL_H`, `LUG_STRAP_W`, `POGO_COUNT`, …).

Экспорт: STL + STEP в `exports/`. Схема размеров: `renders/dimensions.svg`.

## Открыть модель

- **FreeCAD**: File → Open → `exports/case_*.step` (предпочтительно) или STL.
- **PrusaSlicer / Bambu / Cura**: импорт отдельных `case_top.stl`, `case_bottom.stl`, `button_cap.stl`. Ориентация: плоская задняя грань низа на стол; верх — плоскостью разъёма на стол; клавиши — головкой вверх.
- **CadQuery / CQ-editor**: открыть `src/watch_case.py`.

## Привязка к KiCad

Координаты корпуса: **+Y = 12 часов (DISP_MAIN)**, **+X = 3 часа (STRAP_R)**.  
Офсеты KiCad `(dx, dy)` → корпус `(x, −dy)`:

| Ref | KiCad (dx,dy) | Корпус (x,y) |
|-----|---------------|--------------|
| J_DISP_MAIN | (0, −15) | (0, +15) |
| J_STRAP_L | (−15, 0.5) | (−15, −0.5) |
| J_STRAP_R | (15, 0.5) | (15, −0.5) |
| J_BAT | (0, 15.8) | (0, −15.8) |
| SW1..3 | (9.2,12)/(12,9)/(13.5,5.5) | (9.2,−12)/(12,−9)/(13.5,−5.5) |

## Допущения

1. Стекло дисплея — **bounding box**, не OEM CAD.
2. Тонкий LiPo ~3×20×25 mm + foam в полости низа; компоненты PCB делят ту же полость (рядом с батареей).
3. Задняя крышка **пластиковая** ради BLE 2.4 ГГц; NFC нет.
4. Ушки на **3 и 9 часов** (FPC уходит в ремешок); ширина ремешка по умолчанию 20 mm.
5. **IP67 — только design intent**, не lab-certified — см. `reports/IP67_SEALING.md` (особенно sealed pogo).
