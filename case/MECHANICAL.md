# Механика корпуса E Ink часов

## 1. Stack-up (сверху вниз при ношении лицом вверх)

| Слой | Толщина (ном.) | Примечание |
|------|----------------|------------|
| Безель / губа окна | ~0.9–1.5 mm | Удерживает стекло, маскирует край |
| Стекло + E Ink (bbox) | ~1.2–1.4 mm | Не точный OEM; квадрат ~27.6 active |
| Прокладка / gasket | ~0.4–0.6 mm | PORON / silicone cord → IP |
| PCB FR4 | 0.8 mm | Ø40, карман Ø40.3 |
| Компоненты (низ PCB) | до ~3 mm | В общей полости с батареей |
| LiPo pouch + foam | ~3.0 + 0.4 mm | Класс 80–200 mAh; полость **3.6** mm (P0) |
| Канал к pogo | ~1.2 mm высотой | Внутри к зоне J_BAT (6 ч); снаружи sealed wells |
| Задняя стенка | 1.4 mm | **Пластик** (BLE); **blind** pogo wells + elastomer |

**Суммарно по модели: 11.0 mm.** Плоскость разъёма top/bottom **SPLIT_Z=6.0** mm от низа (после P0: `BATTERY_CAVITY_H=3.6`).

**IP:** цель **IP67** (design intent, не сертифицировано). Детали — `reports/IP67_SEALING.md`.


## 2. Маршрутизация FPC к ремешкам

- **MAIN display FPC**: с 12 часов (J_DISP_MAIN) вверх под стекло / в карман — внутри корпуса, без выхода наружу.
- **STRAP_L / STRAP_R**: ZIF на 9 и 3 часа → каналы **10 mm × 0.5 mm** через стенку к ушкам.
- На выходе канала — strain relief (≥0.5 mm) + **grommet/potting для IP67** (сборка).
- Не гнуть COG/жёсткую шейку панели; радиус по datasheet flexible EPD (≥30–33 mm на ремешке — отдельно от корпуса).

Ушки и каналы совмещены по оси 3–9 часов, чтобы flex уходил прямо в левую/правую половину ремешка.

## 3. Кнопки SW1–SW3

Три радиальных тоннеля на нижней-правой дуге (углы ≈ −52°, −37°, −22° от +X), совмещены с размещением PCB:

- SW1 ≈ (9.2, −12), SW2 (12, −9), SW3 (13.5, −5.5) в координатах корпуса.
- `BTN_Z = SPLIT_Z = 6.0` — тоннель режется в **top и bottom** (P0 fix).
- Печатные `button_cap` + **elastomer boot** на OD land (`BTN_BOOT_LAND_D=4.0`) — обязательно для IP67.
- Ход ~0.3–0.5 mm до купола B3U-class.

## 4. Зарядка + SWD — комбинированная pogo cradle (не USB-C)

**Выбор зафиксирован: заднее окно под charge+programming cradle.**

| Параметр | Значение |
|----------|----------|
| Матрица | **2×3 (6 пинов)** |
| Nets | VCHG, GND, SWDIO, SWDCLK, nRESET, OPT |
| Шаг | **3.0 mm** |
| Режим уплотнения | `POGO_SEAL_MODE=elastomer` (alt: `gland`) |
| Сквозные отверстия | **нет** — blind wells, пол ≥0.55 mm |
| Pad recess | Ø2.8 blind под мембраной |
| Окно / карман мембраны | matrix + margin; depth ≤ wall−0.55 |
| Центр окна | (−4.0, −12.5) мм — между J_BAT и J_SWD |
| Ключ | паз на −X (анти-разворот 180°) |
| Допуск соосности | **±0.2 mm** (cradle ↔ case ↔ pads) |
| Канал / keepout внутри | под матрицей к полости PCB |

### Выравнивание (±0.2 mm)

Бюджет погрешности стека:

1. Печать отверстия корпуса (FDM) ≈ ±0.15 mm  
2. Посадка PCB в карман Ø40.3 (зазор 0.15) ≈ ±0.1 mm  
3. Трафарет/позиции B.Cu pads ≈ ±0.05 mm  

Суммарно без датчика легко >0.2 mm — поэтому:  
- направляющие штифты / бортик cradle в окно корпуса;  
- овальные pads на PCB (вытянуты вдоль одной оси) **или** pitch ≥3 mm;  
- при elastomer-режиме допуск относится к pads под мембраной + cradle tips.

PCB: вывести **площадки на B.Cu** под матрицу (via от J_SWD / зарядки) — либо pads вклеены в blind wells с flex внутрь. J_SWD сверху — лабораторный путь; cradle — прод.

Сопряжение: часы **циферблатом вверх** на колодку; cradle pogo **сжимают elastomer** над sealed wells (не входят в сквозные отверстия).

### IP67 и герметизация вокруг pogo (зафиксировано)

**Цель: IP67** (1 m / 30 min). **Не lab-certified.** Подробно: `reports/IP67_SEALING.md`.

Сквозные отверстия **удалены** из CAD (blind wells, пол ≥0.55 mm). Открытая матрица запрещена.

- **Режим по умолчанию:** elastomer лист + conductive pills; cradle сжимает seal (`POGO_SEAL_MODE=elastomer`).  
- **Альтернатива:** per-pin O-ring gland (`POGO_SEAL_MODE=gland`), тоже blind.  
- Split: канавка silicone cord Ø1.0, R=20.7 (`exports/SEAL_PARAMS.txt`).  
- Кнопки: elastomer boots; FPC 3/9: grommet/potting; стекло: PORON + bond land.  
- Винты: глухие вставки + O-ring под головкой.  
- SW_DBG — только внутри, без отверстия в корпусе.  
- NFC/Qi не заложены.

## 5. Бобышки винтов и уплотнение разъёма

- 4 бобышки на окружности **Ø35 mm** (`SCREW_R=17.5`, внутри peripheral gasket), углы 45°/135°/225°/315°.
- Пилот **Ø1.2** под термо-вставку **M1.4** — **глухой** (не пробивает зад).
- Сквозные отверстия в `case_top` Ø1.5; O-ring под головкой для IP.
- По плоскости `SPLIT_Z=6.0`: канавка silicone cord Ø1.0 вырезана (см. `SEAL_PARAMS.txt`).
- FPC-выходы: grommet/potting на сборке.

## 6. BLE / антенна

- Задняя и боковые стенки — **диэлектрик** (PETG/ABS/ASA/нейлон).
- Не металлизировать сплошняком; тонкое декоративное покрытие OK, если есть радиопрозрачное окно у антенны модуля.
- NFC катушки нет — keepout NFC не требуется.

## 7. Печать (FDM)

- Мин. стенки в модели ≥0.8 mm (≥0.4 по ТЗ соблюдено с запасом).
- Нет нулевой толщины; лёгкие фаски 0.25–0.3 mm на наружных кромках.
- Поддержки: ушки (отверстия пружинного стержня), возможно pogo-колодцы при печати низом вверх.
- Допуски: карман PCB +0.15; после калибровки принтера поджать `CASE_ID_CLEAR`.
