## 2. Сопряжения (mates)

### 2.1 PCB Ø40

| Параметр | Значение | Оценка |
|----------|----------|--------|
| PCB | Ø40.0 | — |
| Карман | Ø40.3 (`CASE_ID_CLEAR=0.15`) | **OK** для REV0 |
| Радиальная стенка | (43−40.3)/2 ≈ **1.35 mm** ≥ `WALL_MIN` 0.8 | **OK** |
| Полка PCB | `Z_PCB_BOTTOM=4.6`, `SPLIT_Z=5.6` | согласовано с манифестом |

Interference с бобышками Ø4.2 на R=17.5: кольцо внутри кармана — ожидаемо; keepout на PCB под винты должен совпадать (на стороне KiCad не перепроверялся в этом аудите).

### 2.2 FPC на 3 и 9 часов

| | |
|--|--|
| Канал | `FPC_W×FPC_H = 10×0.4 mm`, длина через стенку `FPC_LEN=8` |
| Ось | ±X, лёгкий `y=+0.5` как у KiCad STRAP |
| Ушки | на **3/9** (не классические 12/6) — осознанно под выход flex в ремешок |

**GAP:** основной вырез FPC в bottom на Z≈4.2–4.75 (ниже `SPLIT_Z`). В top первый cut на том же Z **не пересекает** тело top (`z∈[5.6,11]`); остаётся мелкий `ch2` у плоскости разъёма (~0.4 mm). Полноценный сквозной канал 3/9 через стенку **не гарантирован** после сборки — риск зажима шлейфа / отсутствия strain-relief скругления ≥0.5 mm (заявлено в `MECHANICAL.md`, в CAD не видно).

### 2.3 Pogo 2×3 @ 3.0 mm

| Параметр | Корпус | PCB SoT |
|----------|--------|---------|
| Матрица | 2×3, pitch **3.0** | TP1–TP6, то же |
| Origin | (−4.0, −12.5) | `PCB=(100+x, 100−y)` |
| Отверстия | Ø2.0 + зенковка Ø2.8×0.5 + окно recess 0.8 | pads Ø1.5 B.Cu |
| Ключ | паз −X | cradle anti-180° |
| Align | ±0.2 mm (цель) | совпадает с case SoT |

Координаты совпадают с `exports/POGO_MATRIX.txt` / `POGO_PINOUT.md`.  
**GAP:** бюджет ±0.2 мм при FDM (±0.15) + посадка PCB (±0.1) + pads — на грани; нужны штифты cradle и/или овальные pads (уже отмечено в `MECHANICAL.md`).

### 2.4 SW_DBG — доступ только после открытия

| | |
|--|--|
| Требование PCB | DIP×3 на F.Cu, **без отверстия** в крышке; factory OFF; field → открыть → ON → cradle |
| Позиция PCB | (90.50, 105.50) → **case ≈ (−9.5, −5.5)** |
| Корпус | сквозных окон под SW_DBG **нет** — политика соблюдена |

**OK по доступу.**  
**GAP:** в CAD нет явного keepout/колодца под высоту DIP над F.Cu в общей полости с батареей/компонентами; при сборке проверить, что бобышки/tray/pogo-channel не упираются в пакет SW_DBG. J_SWD остаётся лабораторным путём на открытой плате.

## 4. Gaps / blockers

### Blockers (до функционального прототипа с кнопками / до IP-заявки / до оснастки)

1. **Тоннели кнопок по Z (баг CAD)**  
   - `BTN_Z = Z_PCB_TOP − 0.4 ≈ 5.0`  
   - Top solid: `Z ≥ SPLIT_Z = 5.6` → пересечение тоннеля с top ≈ **1.0 mm** по высоте  
   - В `make_case_bottom` relief кнопок — `pass` (**пусто**)  
   - Итог: полноценного радиального канала под `button_cap` через стенку нет; SW1–SW3 с клавишами не собрать.  
   - **Приоритет P0** правка `BTN_Z` / разрезать тоннель в обеих половинах.

2. **Стекло — bounding box, не OEM**  
   - `GLASS_POCKET ≈ 30×30`, `GLASS_RECESS_H=1.3` — ASSUMED (GDEY0154D67 class).  
   - До закупки панели / обмера — риск переделки безеля. **Blocker для молд-оснастки**, не для печатного «холостого» корпуса.

3. **IP vs pogo**  
   - 6× сквозные Ø2.0 рвут контур. Заявлять IP67 нельзя; реалистично IP52/54 при прокладке split.  
   - **Blocker для водозащиты**, не для сухого REV0.

### Gaps (не стопят форм-фактор / PCB mate)

| # | Тема | Суть |
|---|------|------|
| G1 | Батарея | Tray `~20.6×25.6×3.4` при `BATTERY_CAVITY_H=3.2` — лёгкий overflow по Z; размер pouch ASSUMED (80–200 mAh). Углы tray ≈ R19.7 при лимите полости ~19.95 — на грани. |
| G2 | FPC top | Верхняя половина канала почти отсутствует (см. §2.2); `FPC_H=0.4` может быть мало под ZIF+flex → рассмотреть 0.5. |
| G3 | Канавка gasket на `SPLIT_Z` | В доках «добавить при IP-ревизии» — в модели нет. |
| G4 | Strain relief FPC | Скругление ≥0.5 / силикон — в тексте, не в геометрии. |
| G5 | Align pogo ±0.2 | Оптимистично для FDM без cradle-штифтов. |
| G6 | `COMP_HEADROOM` | Параметр объявлен, в Z-стеке не используется (полость общая с батареей — ок как нарратив, путает стек-ап). |
| G7 | Keepout SW_DBG | Координата (−9.5,−5.5) не отражена в корпусной документации/CAD. |
| G8 | Винты M1.4 | Пилот Ø1.2 / сквозные Ø1.5; длина через стек и высота бобышки под insert — не проверены печатью. |

### Export health

- Единицы mm, STL binary, STEP есть.  
- `case_top` очень лёгкий по треугольникам — следствие простой топологии + слабых вырезов кнопок/FPC, не обязательно non-manifold. Перед печатью — проверка в слайсере (стенки, отверстия pogo).

## 5. Stack-up Z (честность)

```
Z=11.0  верх безеля
        aperture + lip + glass recess (ASSUMED)
Z≈5.9   gasket (ном.)
Z=5.6   SPLIT (разъём top/bottom)
Z=5.4   верх PCB
Z=4.6   низ PCB / полка
Z=1.4   пол полости (батарея+компоненты+канал pogo)
Z=0     наружный back + pogo window
```

Сумма **11.0 mm** зафиксирована параметром `OVERALL_H` (ранний комментарий ~8.7 устарел — redistributed). Компоненты делят полость с LiPo — тесно, но осознанно.
