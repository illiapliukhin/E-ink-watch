# SW_DBG — скрытый переключатель разрешения прошивки через pogo

## Требование
Физический DIP/слайдер внутри корпуса на разрыв возможности прошивки с pogo.
- По умолчанию с завода после прошивки и сборки: **прошивка через pogo ВЫКЛ**
- При проблеме: разобрать часы → включить → прошить через док

## Что рвём (серия)
| Сигнал | Рвём? | Почему |
|--------|-------|--------|
| SWDIO  | да | данные отладки |
| SWDCLK | да | тактирование SWD |
| nRESET | да | иначе можно удерживать в reset с дока |
| VCHG   | нет | зарядка должна работать |
| GND    | нет | общий |
| OPT    | по желанию | обычно NC |

## Топология
```
MCU SWD ──┬── J_SWD (factory header)     — всегда доступен на открытой плате
          │
          └── SW_DBG (DIP-3) ── pogo SWDIO/SWDCLK/nRESET
```
ON = pogo programming enabled  
OFF = factory default sealed product

## Механика
Без отверстия в корпусе. Доступ только после снятия задней крышки.
