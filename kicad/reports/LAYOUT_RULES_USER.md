# Layout rules (user SoT) — antenna / power / SPI / crystal

**Дата:** 2026-09-18 IDT  
**Статус:** обязательные правила размещения для E-ink-watch (и похожих wearable BLE).

## 3. Антенна (Wi-Fi / Bluetooth / ESP32 / nRF module)
- Не размещать медь под антенной.
- Keep-Out вокруг антенны.
- Антенну располагать у края PCB.
- Не помещать рядом аккумулятор или металлический корпус.

## 4. Питание (Li-Po)
- Короткие и широкие дорожки питания.
- Конденсаторы максимально близко к IC.
- Отдельное внимание к DC/DC / LDO.
- GND plane без разрывов вокруг чувствительных цепей.

## 5. Дисплей (SPI)
- CLK / MOSI / MISO / CS — короткие.
- Желательно вести над непрерывным GND.
- Не прокладывать высокоскоростные линии через RF-зону.

## 6. Часы / RTC
- Кварц 32.768 kHz максимально близко к RTC/MCU.
- Дорожки короткие и симметричные, без лишних переходных отверстий.

## Gate
После каждого сдвига footprint: `kicad-cli pcb drc`. Держать `shorting_items=0` и power-priority shorts=0. VBUS на док не подавать, пока shorts не стабильны в нуле.
